# Воркер облачной синхронизации

Cloudflare Worker + KV: хранит личные данные приложения (заметки · закладки ·
теги · прогресс) под **случайным кодом синхронизации**. Ни email, ни паролей —
кто знает код, тот читает и пишет данные под ним.

- `GET  /v1/<code>` → отдать JSON-блоб (или `{empty:true}`)
- `PUT  /v1/<code>` → сохранить блоб (проставляет `_rev`, `_updatedAt`)

Код: 16–80 символов `[A–Za–z0–9-]`. Тело ≤ 2 МБ. CORS — `*` (код и есть секрет).

## Развёртывание (один раз)

Нужен аккаунт Cloudflare (бесплатного тарифа хватает: KV — 100k чтений и
1k записей в день).

```bash
npm install -g wrangler          # если ещё нет
cd sync-worker
wrangler login                   # откроет браузер, войти в Cloudflare

# создать KV-хранилище и вписать его id в wrangler.toml (поле id = "…")
wrangler kv namespace create SYNC

wrangler deploy                  # опубликует воркер, покажет его URL
```

После `wrangler deploy` в выводе будет адрес вида
`https://tafsir-sync.<аккаунт>.workers.dev`.

## Подключение приложения

Вписать этот адрес в `index.html`, в константу рядом с секцией STORAGE:

```js
const SYNC_ENDPOINT="https://tafsir-sync.<аккаунт>.workers.dev";
```

Пусто → синк выключен (в ⚙ Вид показывается «Не настроена»). После заполнения
в ⚙ Вид появляется блок «Синхронизация»: **🔑 Подключить** (создать/ввести код) и
**⟲ Синхронизировать**. Код создаётся на первом устройстве и вводится на
остальных.

## Модель

- **Полуавто:** тихий пул при открытии + кнопка «Синхронизировать» + пуш при
  уходе со страницы (`visibilitychange`/`pagehide`, только если что-то менялось).
- **Слияние — НЕразрушающее** (`applyImport('skip')`): локальные данные не
  затираются; заметки-конфликты остаются свои (полное разрешение конфликтов — в
  файловом Импорте: «оставить мои / дописать обе / заменить»).
- **Компромисс v1:** удаления не распространяются между устройствами (нет
  «надгробий»); удалённая на одном устройстве заметка может вернуться при
  слиянии с другого. Для личного использования на 2–3 устройствах приемлемо.
