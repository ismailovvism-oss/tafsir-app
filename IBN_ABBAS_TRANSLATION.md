# Перевод «Мавсу‘ат ат-тафсир аль-ма’сур» (раздел Ибн Аббаса)

Постоянный стандарт русского перевода источника `ibn_abbas`. Точный формат
блока и словарь имён/терминов — в `data/_sources/ibn_abbas_ru/SPEC.md`. При
расхождении: этот файл задаёт **процесс**, `SPEC.md` — **формат**.

> Процесс намеренно лёгкий: один проход перевода + самопроверка по арабскому +
> механическая сверка скриптом. Это черновой ИИ-перевод «до человеческой
> научной вычитки» — тяжёлая многокомандная схема (двойной перевод, отдельный
> вычитчик) для него избыточна и лишь замедляет работу.

## Цель

Передать по-русски весь смысл арабского оригинала без сокращений, добавлений и
подглядывания в существующий русский перевод. Точно, как исследовательский
текст, и при этом живой русской прозой. Готовый текст остаётся черновым до
человеческой вычитки; автоматические проверки апробацией не являются.

## Какие данные разрешены переводчику

Переводчик получает только:

- `arabic_value` из подготовленного блока;
- канонический арабский текст соответствующих аятов из `context`;
- эту инструкцию и `SPEC.md`.

Нельзя открывать русский `ibn_abbas`, поисковый индекс, старые черновики,
готовые переводы смыслов Корана или машинный перевод этого же блока. Перевод
идёт «вслепую» по арабскому — так цитаты переводятся по смыслу самого
толкования, а не подгоняются под чужой перевод. Существующий русский текст
смотрят лишь потом и только если задача прямо в сравнении/редактуре.

## Граница сверки

Рабочий оригинал — арабский текст подготовленного блока. Внешняя
источниковедческая сверка в обычный перевод НЕ входит:

- не разыскивать асары, цитаты и тахриджи в указанных книгах;
- не проверять номера томов, страниц и хадисов по изданиям;
- не заменять формулировку блока вариантом из другого тафсира;
- библиографию переводить ровно в том виде, как она дана в арабском.

Повреждённый/оборванный фрагмент не реконструировать по внешнему источнику:
передать доступный смысл, минимальное восполнение — в квадратных скобках,
место отметить для человека. Обращение к другим изданиям — отдельная задача по
прямому указанию пользователя.

## Процесс (три лёгких шага на блок)

### 1. Перевод (один проход)

1. Разобрать структуру блока: заголовки-секции, асары, редакторские сводки,
   цитаты, тахриджи, служебные пометы.
2. Перевести каждый элемент по порядку, ничего не объединяя и не переставляя,
   строго по `SPEC.md`.
3. Коранические цитаты — по смыслу данного толкования (жирным, без ﴿﴾), НЕ по
   готовому переводу, если он затемняет разбираемое слово/грамматику.
4. Не сглаживать разногласия авторов; сохранять, кто выбрал, отверг, ограничил,
   уточнил или счёл более вероятным.
5. Сохранять степень уверенности оригинала («возможно», «вероятнее», «очевидный
   смысл») — не превращать в безусловное утверждение.

Один перевод на блок. Двойной независимый перевод и отдельный редактор-сводчик
НЕ делаются — их заменяет самопроверка (шаг 2) и механическая сверка (шаг 3).

### 2. Самопроверка по арабскому (тот же переводчик, сразу после)

Перечитать перевод против арабского и проверить точечно:

- область действия отрицаний, исключений, союзов, придаточных;
- антецеденты местоимений и указательных слов (`هذا القول`, `ذلك`, `منهم`);
- огласовки/морфологию там, где буква меняет субъект или объект
  (`المعتقِد` ≠ `المعتقَد`);
- различие слов автора, передатчика, цитируемого учёного и аята;
- термины: `التخصيص` — ограничение общего, `استدرك` — корректирующее уточнение,
  `لفظ الآية` — формулировка аята, `وجّه القول` — обоснование/направленное
  толкование (не просто «указание»);
- полноту перечислений, условий, причин, выводов, альтернативных мнений.

Правки — только с опорой на арабский. Что осталось спорным — пометить для
человека, а не решать догадкой или пояснением в основном тексте.

### 3. Механическая сверка скриптом

```bash
python3 data/_sources/ibn_abbas_ru/check_translation_block.py SCRATCH SURA
```

Скрипт сверяет структурную парность: число тахриджей `[[...]]`, номеров, знаков
конца аята `۝`, символов почтения, типов секций. Он ловит пропуски, но не
доказывает верность смысла. Сборка запрещена, пока сверка не пройдена.

Ручную структурную сверку по всему списку делать не нужно — за неё отвечает
скрипт; вручную дочитывают только то, что он подсветил.

## Принципы русского текста

- Имена и термины — единообразно по словарю `SPEC.md` (Ибн Джарир, Ибн Атыйя,
  Ибн Касир, Ибн Таймийя, ас-Суюти…).
- Заголовки: `تفسير` — «Толкование», `تفسير الآية` — «Толкование аята»,
  `نزول الآية` — «Ниспослание аята», `القراءات` — «Чтения»,
  `آثار متعلقة بالآية` — «Асары, связанные с аятом», `النسخ في الآية` —
  «Отмена (насх) в аяте».
- Иснад сдержанно и точно: `من طريق فلان` — «путём такого-то».
- Прямая речь — «ёлочками», вложенная — „лапками“.
- Не добавлять пояснений, которых нет в оригинале (короткое разъяснение термина
  — только там, где это предусмотрено `SPEC.md`).
- Повтор оригинала сохранять, если он несёт аргумент, риторику или различает
  цепочки передачи. Литературность — не повод сокращать.
- Формулы вероучения не перетолковывать и не модернизировать; передавать
  позицию источника с его атрибуцией.

## Рабочий процесс для новой партии

```bash
# 1) Подготовить блоки партии
TAFSIR_SURA=11; TAFSIR_FROM=49; TAFSIR_TO=60
SCRATCH=$(mktemp -d /tmp/ibn-abbas-s${TAFSIR_SURA}.XXXXXX)
python3 data/_sources/ibn_abbas_ru/prepare_s3.py \
  "$SCRATCH" "$TAFSIR_SURA" "$TAFSIR_FROM" "$TAFSIR_TO"
mkdir -p "$SCRATCH/s${TAFSIR_SURA}_ru"

# 2) Перевести блоки: SCRATCH/sSURA_blocks/<rep>.json -> SCRATCH/sSURA_ru/<rep>.md
#    (один проход + самопроверка по SPEC). Оптимально — один параметризуемый
#    workflow (инструмент Workflow, файл data/_sources/ibn_abbas_ru/wf_ibn_abbas.js):
#    он сам разведывает список блоков и переводит их параллельно, по агенту на блок.
#      args: { "scratch": "<путь SCRATCH>", "sura": "11", "name": "Худ" }
#    Отдельный wf-скрипт под каждую суру писать НЕ нужно.

# 3) Собрать партию одной командой (сверка -> монолит -> индекс -> fill ->
#    coverage -> config -> валидация):
./assemble_ibn_abbas.sh "$SCRATCH" "$TAFSIR_SURA"
```

Проверить в приложении до публикации:

```bash
python3 -m http.server 8000
# http://localhost:8000/?r2local=1#11
```

`r2local=1` направляет источники с `dataBase` в локальную `r2-data`. Публикация
на R2, коммит и push — отдельные действия, только по прямой просьбе.

## Критерий готовности партии

Партия готова, когда: перевод сделан, самопроверка по арабскому пройдена,
`check_translation_block.py` завершился без ошибок, `assemble_ibn_abbas.sh`
прошёл до конца (включая `validate_data.py`). В changelog — диапазон, число
добавленных записей и число тахриджей.
